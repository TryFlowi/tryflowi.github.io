Política de Privacidade

A sua privacidade é importante para nós. Esta política descreve como o Flowi lida com suas informações.

1. Armazenamento Local

O Flowi funciona como uma aplicação web onde a maioria das informações inseridas (listas, orçamentos e checklists) é salva diretamente no navegador do usuário via LocalStorage. Nós não coletamos nem enviamos esses dados para servidores externos.

2. Coleta de Dados

Não exigimos cadastro ou criação de conta para o uso das ferramentas gratuitas. Caso visite nossa página ou utilize canais de atendimento, dados básicos não sensíveis podem ser coletados via analytics apenas para melhoria de desempenho.

3. Contato

Dúvidas sobre privacidade? Entre em contato pelo nosso Instagram oficial: @tryflowi.
